# Al-Huda: Quran Habit Builder

Nurture your soul, one ayah at a time. Al-Huda is a premium Quran reading habit-building application that combines behavioral psychology, community support, and spiritual growth tracking.

## Project Structure

- `mobile/`: React Native (Bare Workflow) mobile application.
- `backend/`: FastAPI (Python) backend server.
- `docs/`: Technical documentation and guides.

## Tech Stack

- **Frontend:** React Native, TypeScript, Zustand, React Query.
- **Backend:** FastAPI, PostgreSQL, SQLAlchemy, Redis.
- **Infrastructure:** AWS (S3, CloudFront), Firebase (Messaging, Analytics).
